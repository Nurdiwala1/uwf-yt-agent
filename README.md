# UWF YT Agent

Automated YouTube content agent for UWF Reports.

## Locked configuration
- 2 videos/day
- Friday + Sunday: Shorts (30–60 seconds)
- Other days: long-form (5–10 minutes)
- English, male voice
- Topics: Crypto, Finance, Investment, Earning
- Mixed visual style
- Direct public publishing
- Asia/Karachi timezone

## Architecture
Dashboard + API + Supabase + YouTube OAuth + trend research + script generation + voice/visual pipeline + rendering + SEO + scheduled publishing.

Secrets are supplied through environment variables and are never committed to the repository.
